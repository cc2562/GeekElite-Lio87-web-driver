# Leo87 Studio

GeekElite Leo87 的非官方网页驱动首版。使用 WebHID 连接 `320F:5055` 的厂商配置通道 `FF1C:0092`，支持灯光设置、键位读取、有限改键、滚轮方向编辑和备份恢复。

## 启动

需要 Node.js 22 或更新版本，以及支持 WebHID 的桌面 Chrome / Edge。

```powershell
npm install
npm run dev
```

打开 `http://127.0.0.1:5173/`，点击“连接 Leo87”并授权设备。生产环境须使用 HTTPS。

## 数据与安全

- 首次成功读取的 384 字节 keymap 会保存到当前浏览器的 `localStorage`。页面也可以导出当前数据或首次备份为 `.bin`。请自行保留导出的备份；清理浏览器站点数据会删除本地备份。
- 每次连接都会通过 `0x08` 七段事务读取当前配置并刷新界面；不支持该读取方式的固件会回退到已验证的 `0x07` 读取。
- 连接后会独立通过 `0x14` 读取 M1–M10 板载宏。网页支持普通键盘事件实时录制、逐条延时调整、每槽最多 90 条动作，以及 `0x15` 完整写回和 `0x14` 回读校验。
- 键位可绑定 M1–M10，支持正常停止、释放停止、按下停止及播放 1–255 次。宏槽位有未保存内容时，必须先保存宏，再暂存键位绑定。
- 宏数据拥有独立的浏览器首次备份和 `.bin` 导入导出；无法识别的 Header 或事件只允许展示与导出。
- 键盘图上能选择的所有位置都允许重新指定动作，不限制设备读取到的原始编码。滚轮向上/向下分别按原始表中的 record 83/84 编辑；未在键盘图中定位的槽位仍可在原始记录区查看。
- 每次改键都发送 Begin、完整七段 384 字节 SET、End；随后新开事务，通过 `0x08` 七段读取当前生效配置。导入备份必须正好为 384 字节；恢复操作即使回读显示无差异，也允许重新发送完整备份。
- 实机测试中，A 键改为 B 后实体输出已生效，但旧的 `0x07` 读取仍返回写入前的数据。写入后的界面刷新现已统一使用 `0x08`；若当前配置回读仍不一致，页面会提示待确认，且仍可继续编辑或发送备份。
- 灯光发送成功仅表示浏览器完成了报文发送；请观察键盘确认效果。
